# Декомпозиция MVP магазина приложений на Android

**Главная цель:**
Разработать MVP магазина приложений на Android с следующим функционалом:
- Отображение списка приложений
- Отображение карточки приложения
- Установка, удаление приложений

---

## Epic 1. Создание, настройка проекта и создание базы для MVVM архитектуры
**Оценка времени:** 4.5 часа (0.5 дня)
**Цель:** Подготовить пустой проект к началу работы, настроить библиотеки и базовый дизайн.

**Задачи:**
1. Создать проект в Android Studio и добавить все нужные для проекта зависимости.
   *Оценка: 1 час*
2. Создать базовую структуру папок (presentation, data, domain слои) для архитектуры MVVM.
   *Оценка: 0.5 часа*
3. Настроить тему: задать первичные цвета для светлой и темной темы, а также шрифты по макету.
   *Оценка: 1.5 часа*
4. Настроить Git, создать репозиторий на GitHub и сделать первый коммит (Initial commit).
   *Оценка: 1.5 часа*

## Epic 2. Список приложений
**Оценка времени:** 14 часов (1.75 дня)
**Цель:** Пользователь открывает приложение и видит список доступных приложений.

**Задачи:**
1. Создать дата-класс AppDetails, который содержит всю самую нужную информацию о приложении (id, название, разработчика, категорию, размер, иконку, возрастной рейтинг, описание).
   *Оценка: 0.5 часа*
2. Сделать репозиторий заглушку и его реализацию, которая будет возвращать список из 10-15 приложений.
   *Оценка: 1.5 часа*
3. Реализовать usecase для получения списка приложений.
   *Оценка: 0.5 часов*
4. Реализовать ViewModel для списка: сделать загрузку данных и стейты (загрузка, ошибка, готовый список).
   *Оценка: 2 часа*
5. Сверстать элемент списка (карточку одного приложения).
   *Оценка: 2.5 часа*
6. Сверстать сам экран со списком через LazyColumn и передать туда данные из ViewModel.
   *Оценка: 2.5 часа*
7. Сделать обработку состояния загрузки (крутилку через CircularProgressIndicator) и пустой ошибки.
   *Оценка: 1.5 часа*
8. Добавить навигацию (NavHost), чтобы при клике на карточку приложения пользователь переходил на пустой экран заглушку.
   *Оценка: 1.5 часа*
9. Ручное тестирование экрана, проверка переходов и исправление выявленных багов.
   *Оценка: 1.5 часа*

## Epic 3: Карточка приложения
**Оценка времени:** 11.5 часов (1 день 3.5 часа)
**Цель:** Отображение детальной информации о выбранном приложении.

**Задачи:**
1. Создание usecase'ов (GetAppDetails, ObserveAppDetails, ToggleWishlist). Реализация AppDetailsViewModel с обработкой AppDetailsState (Loading, Error, Content) и AppDetailsEvent через Channel.
   *Оценка: 2.5 часа*

2. Реализация Toolbar (с кнопками назад, вишлист, поделиться), AppDetailsHeader (иконка, рейтинг, размер) и Developer.
   *Оценка: 2 часа*

3. Реализация ScreenshotsList (через HorizontalPager) и AppDescription (с логикой сворачивания/разворачивания текста collapsed).
   *Оценка: 2 часа*

4. Создание экранов AppDetailsLoading, AppDetailsError и базовой кнопки InstallButton.
   *Оценка: 1 час*

5. Объединение компонентов в AppDetailsContent. Настройка корневого AppDetailsScreen (Scaffold, обработка SnackbarHost, подписка на state и events из ViewModel).
   *Оценка: 2.5 часа*

6. Ручное тестирование экрана и исправление выявленных багов.
   *Оценка: 1.5 часа*

## Epic 4: Установка и удаление приложений
**Оценка времени:** 13 часов (~1.6 дня)
**Цель:** Реализовать жизненный цикл приложения: скачивание APK, вызов системного установщика, удаление и обновление статусов в UI.

**Задачи:**
1. Добавить необходимые разрешения в AndroidManifest (INTERNET, REQUEST_INSTALL_PACKAGES).
   *Оценка: 0.5 часа*

2. Написать сервис загрузки APK-файла через DownloadManager с возможностью отслеживать процент скачивания.
   *Оценка: 3 часа*

3. Написать функции для запуска системного окна установки скачанного APK и вызова окна удаления через Intent.ACTION_DELETE.
   *Оценка: 2 часа*

4. Добавить логику хранения и обновления статуса (Не установлено / Скачивается X% / Установлено). Сделать так, чтобы статус синхронизировался между главным списком и карточкой приложения.
   *Оценка: 3 часа*

5. Подключить логику к кнопке InstallButton: менять её вид в зависимости от статуса (показывать прогресс-бар при скачивании, менять текст на "Удалить" или "Открыть").
   *Оценка: 2.5 часа*

6. Добавить обработку простых ошибок (нет интернета, пользователь не дал права на установку) и провести ручное тестирование полного цикла.
   *Оценка: 2 часа*
